# OAWeekend Documentation

This documentation is the source of truth for OAWeekend setup, integrations, operating procedures, and project history.

## What this includes

- Tutorials: onboarding paths for new contributors and agents.
- How-to guides: task-oriented runbooks.
- Reference: facts, inventories, contracts, and system maps.
- Explanation: architecture, roadmap, and design rationale.
- Decisions: ADRs and durable decision history.
- Log: append-only work chronology.

## Audience

- Team members maintaining OA Weekend.
- Agents supporting implementation, review, deployment, and operations.

## Fast path

1. Read [Agent Quickstart](agents/start-here.md).
2. Use [System Map](reference/system-map.md) to locate the owning surface.
3. Use [Integration Inventory](reference/integration-inventory.md) before changing external data pulls.
4. For Planning Center work, start with [Planning Center Wrapper](planning-center-wrapper.md).
5. For Rock work, start with [Rock RMS Integration](rock-integration.md).
6. Check [Wiki Log](log.md) for recent deploys, verification, and project decisions.

## Wiki schema

This folder also serves as an LLM-maintained Obsidian vault. See [wiki-schema.md](wiki-schema.md) for the schema, operations, and conventions. Activity is tracked in [log.md](log.md). Structured frontmatter queries live in [wiki.base](wiki.base).

## Content catalog

The list below is generated by the Obsidian Dataview plugin. It appears as a live table inside Obsidian and as a plain code block on GitHub.

```dataview
TABLE WITHOUT ID
  file.link AS "Page",
  file.folder AS "Folder",
  file.mtime AS "Modified"
FROM ""
WHERE file.name != "index" AND file.name != "log" AND file.name != "wiki-schema"
SORT file.folder ASC, file.name ASC
```
